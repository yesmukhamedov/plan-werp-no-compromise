# EPIC-001. Организация проекта

## Зачем

Ни один инвентаризационный эпик не выполним, пока нет людей, которые его
выполняют, и людей, которые отвечают на вопросы. Этот эпик — первая неделя
проекта.

## Результат

- Команда собрана, роли назначены поимённо.
- У каждого домена есть владелец со стороны бизнеса.
- Время носителей знания забронировано.
- Ритм работы установлен и запущен.

## Задачи

### TASK-0101. Подтвердить состав команды

Численность, роли, доля занятости, срок доступности.

**Приёмка:** [OQ-001](../docs/08-risks/02-open-questions.md#oq-001) закрыт;
оценки в [07-estimates.md](../docs/05-plan/07-estimates.md) переведены в
календарь.

### TASK-0102. Назначить владельцев доменов

По одному человеку на домен из [карты](../docs/03-target/02-domain-map.md).
Владелец отвечает на вопросы, принимает решения о расхождениях, подписывает
приёмку.

**Приёмка:** таблица «домен → владелец» заполнена полностью; владельцы
уведомлены и подтвердили готовность.

### TASK-0103. Назначить проектные роли

Руководитель проекта, архитектор, ответственный за данные, ответственный за
инфраструктуру, руководитель переезда (может быть назначен позже, но роль
объявлена сразу).

**Приёмка:** роли закреплены поимённо; зона ответственности каждой описана.

### TASK-0104. Забронировать время носителей знания

Разработчики и пользователи, знающие текущую систему. Это ограничивающий фактор
Фазы 0 ([R-08](../docs/08-risks/01-risk-register.md#r-08)).

**Приёмка:** график интервью на первый месяц согласован.

### TASK-0105. Запустить ритм

Еженедельный отчёт, демонстрации раз в две недели, ежемесячная ретроспектива и
пересмотр рисков ([00-roadmap.md](../docs/05-plan/00-roadmap.md#ритм)).

**Приёмка:** встречи в календаре; первый отчёт выпущен.

### TASK-0106. Включить сбор данных об использовании в легаси

Обращения к эндпойнтам, запуски отчётов, запросы к таблицам. Без этих данных
решения «переносим / не переносим» принимаются по памяти
([OQ-014](../docs/08-risks/02-open-questions.md#oq-014)).

**Приёмка:** сбор работает; данные накапливаются; первый отчёт за неделю
получен.

> Выполнить в первую неделю: чем раньше начнётся сбор, тем репрезентативнее
> выборка к моменту принятия решений. Месяц данных лучше недели.

### TASK-0107. Объявить проект

Сообщить пользователям и бизнесу: что делаем, зачем, что изменится, когда
вводится заморозка.

**Приёмка:** объявление сделано; вопросы собраны и отвечены.

> Заморозка, введённая без объявления, воспринимается как саботаж со стороны
> разработки ([05-freeze-policy.md](../docs/04-migration/05-freeze-policy.md#коммуникация)).

## Критерии закрытия эпика

- [ ] OQ-001 закрыт
- [ ] Все домены имеют владельцев
- [ ] Проектные роли назначены
- [ ] Сбор данных об использовании работает
- [ ] Ритм запущен
- [ ] Проект объявлен

# Архитектурные решения (ADR)

Одно решение — один файл. Файл не удаляется и не переписывается задним числом:
если решение отменено, оно получает статус «Заменено» и ссылку на преемника.
Так сохраняется не только результат, но и причина.

Шаблон — [templates/ADR.md](../../templates/ADR.md).

## Статусы

| Статус | Значение |
|---|---|
| `Предложено` | сформулировано, обсуждается |
| `Принято` | действует, обязательно к исполнению |
| `Отложено` | решение сознательно не принимается; указан срок и условие |
| `Заменено` | отменено другим ADR (указана ссылка) |
| `Отвергнуто` | рассмотрено и отклонено; сохранено ради причины отказа |

## Гейты

Гейт — контрольная точка, до которой перечисленные решения обязаны быть в
статусе «Принято». Определение гейтов — [transition/plan/00-roadmap.md](../../transition/plan/00-roadmap.md#гейты).

## Как добавить решение

1. Скопировать [templates/ADR.md](../../templates/ADR.md) в
   `ADR-NNNN-краткое-имя.md` со следующим свободным номером.
2. Заполнить контекст, варианты, решение, последствия. **Отвергнутые варианты
   описываются с той же честностью, что и принятый** — иначе ADR бесполезен.
3. Добавить строку в реестр выше.
4. Открыть PR. Статус меняется на «Принято» только после слияния.
